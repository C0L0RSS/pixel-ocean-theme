# Pixel Ocean

An 8-bit pixel-art ocean behind your conversation in the Claude Code desktop app.

The water is drawn on a 320×200 pixel grid, scaled up with crisp edges, and everything moves one pixel at a time, like an old console game:

- a coral crab scuttling back and forth on the seabed
- schools of teal, gold and pink fish
- a slow-paddling sea turtle
- two glowing jellyfish bobbing along the edges
- swaying seaweed, rising bubbles, drifting marine snow and stair-stepped sunbeams
- dithered water bands that darken with depth, and surface waves rolling past overhead

The app's own colors change too: deep-sea navy panels with a coral accent, made for dark mode. The creatures keep to the edges, the top and the seabed, so the chat in the middle stays easy to read behind lightly frosted glass. If your system asks for reduced motion, the scene holds still.

## Install

At the prompt of a terminal session:

```
/plugin install pixel-ocean --marketplace C0L0RSS/pixel-ocean-theme
```

From a shell:

```
claude plugin install pixel-ocean --marketplace C0L0RSS/pixel-ocean-theme
```

In the desktop app, where `/plugin` does not run: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `C0L0RSS/pixel-ocean-theme`, then **Add plugin**.

The scene needs an up-to-date Claude Code desktop app and a local session in the **Code** tab. The terminal keeps its own colors.

Only one theme shows at a time, so turn off any other theme mod you have installed.
